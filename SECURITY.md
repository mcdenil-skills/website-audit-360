# Security Policy

## Сообщить о проблеме

Не публикуйте действующие токены, пароли, ключи, персональные данные и детали уязвимости в публичном issue.

Используйте GitHub Security Advisory в репозитории или свяжитесь с администраторами организации `mcdenil-skills` через приватный канал GitHub.

## Scope

Этот репозиторий содержит инструкции Agent Skill и не запускает собственный сетевой сервис.

Сообщайте о проблемах, если skill:

- предлагает несанкционированное активное тестирование;
- выводит или сохраняет секреты/ПДн;
- утверждает юридическое соответствие без оснований;
- разрешает destructive действия без подтверждения;
- содержит небезопасную команду установки или выполнения.

Не тестируйте сторонние сайты или аккаунты без разрешения владельца.
