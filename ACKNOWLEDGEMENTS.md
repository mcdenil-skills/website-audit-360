# Благодарности и открытые основы

`website-audit-360` использует собственную структуру и формулировки, но опирается на открытые стандарты и идеи следующих проектов.

## Стандарты

- OWASP Application Security Verification Standard 5.0 — карта технических требований безопасности.
- W3C WCAG 2.2 и WCAG-EM — доступность и методика выборки страниц.
- Google Lighthouse — лабораторная проверка performance, accessibility, best practices и SEO.

## Agent Skills и инструменты

- `TarkinLarson/asvs-auditor` (MIT) — доказательная привязка security findings к OWASP ASVS.
- `AccessLint/skills` — workflow accessibility scan/audit/fix/diff.
- `browser-use/browser-use`, skill `qa` (MIT) — проверка реальных пользовательских flows в браузере.
- `Abhishek-Chougule/website-standards-auditor` (MIT) — идеи статического аудита форм, CTA, SEO и repository hygiene.
- `AlsKozlov/ru-legal` (Apache 2.0) — стартовая структура российского legal launch review.
- `FuzulsFriend/compliance-auditor` (MIT) — принцип сверки юридических заявлений с реальными data flows.

Чужой текст и шаблоны не включены в этот репозиторий. Ссылки служат для атрибуции идей и дальнейшего изучения. Каждая внешняя система остаётся под своей лицензией.
